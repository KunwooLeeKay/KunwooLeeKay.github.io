Physical Therapy Assessment Automation from Uncalibrated Inputs

Uncalibrated RGB + IMU pipeline for automated PT performance evaluation

Computer Vision IMU Sensor Fusion Machine Learning Physical Therapy

Overview

We present a fully automated physical therapy assessment system that eliminates the need for manual calibration. Using uncalibrated multi-view RGB cameras and wearable IMUs, our pipeline automatically calibrates camera extrinsics and aligns IMU orientations to anatomical axes, then fits a statistical body model to extract joint kinematics. A kinematics-driven classifier trained on 38 subjects performing step-up exercises achieves classification performance that approaches inter-clinician agreement when using multiple camera views.

By removing calibration barriers while maintaining clinical-grade accuracy, this work demonstrates that automated movement assessment can be deployed in both clinical facilities and home environments, making high-quality rehabilitation monitoring accessible to patients regardless of their care setting.
